选择设计路径与难度

三大方法论 × 多级难度，为你的项目匹配最合适的设计框架

问题驱动设计

从用户痛点出发 → 定义问题 → 生成方案

🌱 初级
6个节点

痛点速解 · 轻量版：用户画像 → 核心痛点 → 问题定义 → 解决方案 → 方案选择

适用于：课程作业、小型设计任务

🚀 中级
13个节点

需求驱动 · 标准版：用户调研 → 痛点聚类 → 功能定义 → 方案发散 → 评估矩阵 → 测试反馈

适用于：毕业设计、初创产品MVP

🎯 高级
12个节点

战略牵引 · 深度版：大规模调研 → 竞品分析 → 用户细分 → 需求优先级 → 架构规划 → 落地计划

适用于：企业级产品、复杂系统

解决方案驱动设计

从创意/技术出发 → 概念发散 → 验证落地

✨ 初级
5个节点

概念速创 · 轻量版：核心概念 → 应用场景 → 用户群体 → 可行性评估

适用于：头脑风暴、创意工作坊

⚡ 高级
10个节点

技术转化 · 深度版：核心技术 → 概念放射 → 多路径探索 → 方案评估 → 原型验证 → 商业化

适用于：技术驱动项目、创业创意

双钻模型设计

发现 → 定义 → 发展 → 交付 完整流程

💎 初级
8个节点

钻石雏形 · 轻量版：发现→定义→发展→交付（简化四阶段，每阶段2个节点）

适用于：设计思维初学者、小型工作坊

🔷 中级
12个节点

双钻淬炼 · 标准版：四阶段完整节点+阶段间迭代反馈

适用于：完整设计项目、毕业设计

💠 高级
16个节点

大师锻造 · 深度版：大规模调研+系统建模+多方案收敛+战略交付

适用于：企业级项目、复杂系统设计

初级：引导式设计，适合新手快速上手
中级：完整设计流程，适合常规项目
高级：深度系统化设计，适合复杂项目
